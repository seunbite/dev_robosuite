# Upstream robosuite

This repository is a research fork of
[ARISE-Initiative/robosuite](https://github.com/ARISE-Initiative/robosuite).
The `robosuite/` package and its assets retain upstream attribution and license.

Paper-specific changes include embodiment models, inverse-kinematics behavior,
gesture renderers, and Motion Program execution. Keep upstream updates separate
from paper-data commits so simulator changes remain auditable.
