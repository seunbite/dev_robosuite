[Coordinate frame]
World frame: **+x = forward toward the human viewer**, **+y = robot left**, **+z = up (ceiling)**.
The right arm is the primary gesturing arm unless `left_arm=mirror` (or an independent left dir) is set.
EE percentiles (`x`, `y`, `z`, each 0–100) refine the right-hand fingertip in the workspace:
- **(50, 50, 50) = body center** (chest / midline baseline for the chosen `dir`).
- **0 / 100 = extrema** on that axis (most back/right/low vs forward/left/high). Spans 0–50 and 50–100 may be asymmetric in meters.
- **x**: depth — forward / back (higher ≈ farther toward viewer).
- **y**: lateral — left / right (higher ≈ more toward robot left / +y). For **midline / palms-together / chest-center**, use **y≈50** (not x).
- **z**: height — up / down (higher ≈ face/head height; lower ≈ waist). Default omitted axes = 50.

[Motion Code — pose]
`pose(dir=..., grip=..., head=..., torso=..., left_arm=..., elbow=..., x=..., y=..., z=..., t=...)`
Join steps with `+`.

1. Arm direction (`dir` → `arm_position`) — dominant reach of the right arm:
- **front**: reach toward the viewer (+x). Example: offer, point forward, handshake.
- **back**: reach toward own torso (−x). Example: hand on chest, retract.
- **in**: reach inward across / toward midline (+y from the right arm). Example: beckon, palms together, rub chest.
- **out**: reach outward to the side (−y). Example: side wave, open branch.
- **up**: reach toward the ceiling (+z). Example: stretch, surrender.
- **down** / **still**: lowered / rest. **Omit `dir` or set `still` for head-only cues** (nod, shake, tilt) so arms do not invent a raised pose.

2. Gripper / hand (`grip`) — wrist class and optional palm normal:
- Wrist class: **vert** / **vertical** (jaw line **|**) or **horiz** / **horizontal** / **open** (jaw line **ㅡ**).
- Palm compounds (humanoid bank): combine with `|` — `vert|palmin`, `horiz|palmdown`, `horiz|palmup`, `horiz|palmfront`, `horiz|palmback`.
  - **palmin**: palm toward midline / body. **palmfront**: palm toward viewer (stop / high-five).
  - **palmup** / **palmdown**: open-hand invite / press-down. **palmback**: fist back toward self.
- **close** / **closed** / **pinch**: maps to vertical clenched (fist cues).
- Prefer a compound when palm facing is semantically load-bearing (stop, shrug, welcome, fist).

3. Head (`head`): `center` | `left` | `right` | `up` | `down` — preset gaze. Default `center`.

4. Torso (`torso`): `low` | `mid` | `high` | `tall` (=high). Default `mid`.

5. Left arm (`left_arm`, optional, default still):
- **still**: left arm stays at rest.
- **mirror**: left copies the right arm direction (symmetric: stretch, surrender, palms together, hug). **Use mirror when both arms share the same direction** — do not set left to the same categorical value as right.
- Or an independent `dir` value when left differs from right.

6. Elbow (`elbow`, optional): `T` / `true` / `F` / `false` → `elbow_bended`. Use `T` for flexed salutes / raised-index / draw-circle; `F` for straight point / reach.

7. EE percentiles (`x`, `y`, `z`, optional 0–100): see coordinate frame above. For hands meeting at chest centerline use `dir=in`, `left_arm=mirror`, and **y≈50**; **do not** treat `x=50` as left–right center.

[Motion Code — move / path / hold]
`move(joint, axis, degrees, rep=..., spd=..., hold=...)`
`path(ee|base, line|arc, ...)`
`hold(t=...)`

**Read the opening pose first**, then design **1–7 follow-on steps**.
`hold(t=…)` is a first-class beat (pose + hold is valid for static emblems: point, stop, welcome).
Parser rewrites `hold` to a zero-distance EE line with `hold_time`.

[move — joint-space beats]
1. Joints / axes:
- **shoulder** | **elbow** | **wrist**: axes `x`, `y`, `z` (depth / lateral / height).
- **head**: `pan` (left/right), `tilt` (up/down), degrees relative to current pose.
- **torso**: `height` with categorical `low|mid|high`, or small cartesian proxies (`x` lean in meters).
- Degrees: a scalar `−20` means one-way `[0, −20]`; `±15` or `[-15,15]` means ping-pong; `[20]` is a one-sided list.
2. Speed (`spd`): 0.3 (slow) – 4.0 (sharp). Vary setup / core / settle.
3. Hold (`hold` seconds): 0.15–1.5 so the viewer sees move → hold → move.
4. Repetition (`rep`): identical repeats (nod 3×). Asymmetric rhythms → separate steps.

[path — Cartesian]
- EE line: `path(ee, line, axis=x|y|z, dist=±meters, spd=..., hold=..., rep=...)`
- EE arc: `path(ee, arc, plane=xy|xz|yz, r=meters, sweep=degrees, spd=..., rep=...)`
- Base line/arc: `path(base, line, x=..., y=...)` or `path(base, arc, r=..., deg=...)` (rare on humanoid)
- Typical EE stroke: 0.03–0.25 m; arc radius 0.03–0.20 m; tiny rub arcs ≈0.01–0.03 m.
