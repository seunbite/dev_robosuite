[Coordinate frame]
Planar world: **+x = forward toward the human viewer**, **+y = robot left**, yaw positive ≈ left turn.
There is **no z arm workspace**. Do not emit arm `dir`/`grip`/`x/y/z` percentiles meant for manipulators.

[Motion Code — pose / path / hold]
`pose(dir=front|back|left|right)` — facing only (optional; most cues are path-only).
`path(base, line, x=±m, y=±m, spd=..., hold=..., rep=...)`
`path(base, arc, r=m, deg=±degrees, spd=..., hold=..., rep=...)`
`hold(t=...)`
`move(...)` is discouraged; if emitted it becomes a tiny in-place yaw wiggle only.
Join steps with `+`.

1. Facing (`pose` / `dir`):
- **front**: face the viewer. **back**: face away. **left** / **right**: face sideways.
- Use a facing pose when orientation itself carries meaning; otherwise skip pose and start with `path`/`hold`.

2. Base line:
- `x`: forward (+) / back (−) meters. `y`: left (+) / right (−) meters.
- Typical approach: `x=+0.15`–`+0.40`. Small scoots: `0.05`–`0.15`. Lateral sway: `y=±0.05`.
- Oscillation forms:
  - `x=±0.15` with `rep` (ping-pong)
  - `x=[0.20, -0.15]` explicit out-and-back list
- Pure freeze: `hold(t=…)` alone is allowed for “stillness” emblems (embarrassed pause, tree, facepalm proxy).

3. Base arc:
- `r`: turning radius (m). **`r=0`** = rotate in place (nod/shake/tilt proxies via yaw).
- `deg`: signed sweep (positive ≈ CCW / left). Use `±30` / `deg=[+22,-22]` for oscillatory yaw.
- Full loops / orbits: `deg=360` (or 720 for spin emphasis) with optional `rep`.
- Figure-eight / flying: prefer **linked opposing arcs** (two sweeps of opposite sign) over identical carousel spins.

4. Hold:
- `hold(t=0.3–2.5)` so the viewer sees stroke → pause → stroke.
- Parser rewrites `hold` → zero-`x` base line with `hold_time`.

[Timing]
- Speed (`spd`): 0.3 (slow) – 4.0 (sharp). Soft approach; sharp strike. (Occasional >4.0 only for extreme spin emphasis.)
- Repetition (`rep`): identical repeats only. Asymmetric rhythms → separate steps.
