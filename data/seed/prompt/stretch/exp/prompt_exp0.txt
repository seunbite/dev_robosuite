[Coordinate frame]
World: **+x = forward toward the human viewer**, **+y = robot left**, **+z = up (ceiling)**.
Stretch maps: `torso` → vertical lift; `dir` → arm extension + wrist; `x` → telescope; `z` → lift height; `y` → wrist yaw.

[Motion Code — pose]
`pose(dir=..., grip=..., head=..., torso=..., elbow=..., x=..., y=..., z=...)`
Join steps with `+`.

1. Arm direction (`dir` → `arm_position`):
- **front** / **back** / **in** / **out** / **up** / **down** / **still**.
- Omit `dir` or use **still** for head-only cues so the arm stays retracted.

2. Gripper (`grip`) — simple wrist class only:
- **vert** / **vertical** | **horiz** / **horizontal** / **open**.
- Do **not** emit palm compounds or `left_arm`.

3. Head (`head`): `center` | `left` | `right` | `up` | `down`. Default `center`.

4. Torso / lift (`torso`): `low` | `mid` | `high` | `tall` (=high). Default `mid`.

5. Elbow (`elbow`, optional): `T`/`true` or `F`/`false` → biases wrist pitch.

6. EE percentiles (`x`,`y`,`z`, optional 0–100): telescope / wrist-yaw / lift.

[Motion Code — move / path / hold]
`move(joint, axis, degrees, rep=..., spd=..., hold=...)`
`path(ee|base, line|arc, ...)`
`hold(t=...)`

Joint aliases on Stretch:
- **shoulder** → arm telescope wave
- **elbow** → wrist pitch
- **wrist** → wrist yaw/roll
- **head** → pan|tilt
- **torso** → lift height
