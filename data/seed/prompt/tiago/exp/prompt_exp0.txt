[Coordinate frame]
World: **+x = forward toward the human viewer**, **+y = robot left**, **+z = up (ceiling)**.
The right arm is the primary gesturing arm unless `left_arm=mirror` (or an independent left dir) is set.
EE percentiles (`x`, `y`, `z`, each 0–100):
- **(50, 50, 50) = body / torso center**; 0/100 = extrema.
- **x** depth, **y** lateral (y≈50 = midline), **z** height. Omitted axes default to 50.

[Motion Code — pose]
`pose(dir=..., grip=..., head=..., torso=..., left_arm=..., elbow=..., x=..., y=..., z=...)`
Join steps with `+`.

1. Arm direction (`dir` → `arm_position`):
- **front** / **back** / **in** / **out** / **up** / **down** / **still**.
- Omit `dir` or use **still** for head-only cues so arms stay lowered.

2. Gripper (`grip`) — Tiago bank uses **simple** wrist class only:
- **vert** / **vertical** | **horiz** / **horizontal** / **open**.
- **close** / **closed** → vertical clenched.
- Do **not** emit palm compounds (`vert|palmin`, …) on this platform — they are humanoid-only.

3. Head (`head`): `center` | `left` | `right` | `up` | `down`. Default `center`.

4. Torso (`torso`): `low` | `mid` | `high` | `tall` (=high). Default `mid`.

5. Left arm (`left_arm`, optional, default still):
- **still** | **mirror** | or an independent `dir` when left ≠ right.
- Use **mirror** for true bimanual symmetry (stretch, surrender, welcome, palms together).

6. Elbow (`elbow`, optional): `T`/`true` or `F`/`false` → `elbow_bended`.

7. EE percentiles (`x`,`y`,`z`, optional 0–100): refine within the same (`dir`,`grip`,`elbow`) class.

[Motion Code — move / path / hold]
`move(joint, axis, degrees, rep=..., spd=..., hold=...)`
`path(ee|base, line|arc, ...)`
`hold(t=...)`

`hold(t=…)` is valid after a pose for static emblems (point, stop, thank-you freeze).
Parser rewrites `hold` → zero-distance EE line with `hold_time`.

[move — joint-space]
1. Joints / axes:
- **shoulder** | **elbow** | **wrist**: axes `x`, `y`, `z`.
- **head**: `pan` | `tilt`.
- **torso**: `height` (categorical low|mid|high) or small cartesian lean (`x` meters).
- Degrees: scalar = one-way; `±15` / `[-15,15]` = ping-pong.
2. `spd` 0.3–4.0. `hold` 0.15–1.5s. `rep` for identical repeats only.

[path — Cartesian]
- EE line: `path(ee, line, axis=x|y|z, dist=±m, spd=..., hold=..., rep=...)`
- EE arc: `path(ee, arc, plane=xy|xz|yz, r=m, sweep=deg, spd=..., rep=...)`
- Base (optional): `path(base, line, x=..., y=...)` / `path(base, arc, r=..., deg=...)`
- Typical EE stroke 0.03–0.25 m; arc radius 0.03–0.20 m.
