[pose Selection Rules]
Coordinate frame (world): +x = forward toward the human viewer, +y = robot left, +z = up (ceiling). The right arm is the primary gesturing arm unless `left_arm` says otherwise.

1. Arm position (`arm_position`) — dominant reach direction of the right arm:
Choose from where the arm extends relative to the torso:
- **front**: reach toward the viewer (+x). Example: offer object, point forward, handshake reach.
- **back**: reach toward own torso (−x). Example: hand on chest, retract inward.
- **in**: reach inward across the body (+y from the right arm). Example: beckon, touch face, rub chest.
- **out**: reach outward to the side (−y). Example: side wave, lateral present, open branch.
- **up**: reach toward the ceiling (+z). Example: stretch, surrender, hail.
- **down**: reach downward (−z). Example: point at floor, lowered palm.

3. Gripper orientation (`gripper_orientation`):
The **end line** is the jaw-opening line (between fingertip tips). Take the plane **perpendicular** to the arm reach direction. **Orthogonally project** the end line onto that plane. An observer stands **facing that plane** (looking straight at it). Read the projected line:
- **horizontal**: projected line is a **ㅡ** (left–right). Example: wave, high-five, stop palm-out.
- **vertical**: projected line is a **|** (up–down). Example: handshake, point, beckon flick.

Examples: wave → out + horizontal; handshake → front + vertical; stretch → up + horizontal.

4. Head (`head`) — preset gaze from the robot's perspective:
- **center**: look forward. **left** / **right**: pan sideways. **up** / **down**: tilt toward ceiling / floor.

5. Left arm (`left_arm`, optional, default still):
- **still**: left arm stays at rest.
- **mirror**: left arm copies the right arm's `arm_position` (symmetric gestures: stretch, surrender, hug). **Use mirror when both arms share the same direction** — do not set `left_arm` to the same value as `arm_position` (e.g. both `"in"`).
- Or any `arm_position` value for independent left-arm placement (only when left differs from right).

6. Elbow bended (`elbow_bended`, optional):
- **true** / **false** — refines which joint configuration is used within the same (`arm_position`, `gripper_orientation`) class.

7. EE percentile (`x`, `y`, `z`, optional, each 0–100):
Percentile coordinates of the right-hand gripper fingertip in the workspace. They refine **which sample** is chosen for the same `arm_position` + `gripper_orientation` (+ `elbow_bended`). Use higher `z` for face/head-height, lower for waist; adjust `x`/`y` for forward/back and inward/outward bias.

[Movement / Path Rules]
Coordinate frame: +x forward (viewer), +y robot left, +z up.

**Read the opening pose first** — how the arm extends and how the gripper reads — then design **1–7 follow-on steps** that only make sense from that configuration.

Examples:
- beckon: start `in` + `vertical` → small **path** ee line on **y**, `repetition` 3–4 — not a large shoulder reposition.
- nod yes: start arms `down` + head `center` → **movement** on `head` / `tilt`, `repetition` 3.
- blow_kiss: start `up` + `horizontal` → **path** ee line **+x** (forward puff), `repetition` 1.
- facepalm: start `in` + `vertical` near face → **path** ee line **−x** with `hold_time` ≥ 0.15s.
- pat/rub: start hand on body → **path** ee line on local axis (x/y/z), `repetition` 3–4 with `hold_time`.

[Movement steps — joint-space beats]
Use `type: "movement"` for discrete beats (arm / head / torso).

1. Joint and axis mapping (`movement.joints[]`):
- **shoulder** | **elbow** | **wrist**: axes `x`, `y`, `z`.
- **head**: axes `pan` (left/right), `tilt` (up/down), degrees relative to the current pose.
- **torso**: axis `height` only — `degrees` [lo, hi] in **meters** (low≈0.05, mid≈0.18, high≈0.34).
- **right_arm** / **left_arm**: axes `x`, `y`, `z` when needed.
- x: depth (forward/back), y: lateral (side-to-side / wave), z: height (up/down / nod).
- No `base` joint in movement.

2. Speed (per movement step):
- Range: 0.3 (slow) – 4.0 (sharp). Default: 0.8–2.0.
- Vary: setup 0.6–1.2, core 1.5–3.5, settle 0.5–1.0. Avoid all beats at 3–4 unless one sharp strike.

3. Pause / hold (`hold_time` seconds, per movement or path step):
- Use 0.15–0.8s so the viewer sees move → hold → move.
- Multi-beat cues (beckon, shh, rub, pat): at least one hold ≥ 0.25s between beats.

4. Repetition (`repetition` on movement or path):
- Same joint/axis/range or path stroke repeated identically (head tilt nod 3×, path y ping-pong 4×).
- Asymmetric rhythms (move–pause–move–move): use **separate steps** — not `repetition` 4 at speed 4.0 with hold 0.

5. Angle / range (`degrees` per joint entry):
- shoulder/elbow/wrist rotational axes: typical ±5–45° (wrist ±5–20; shoulder/elbow ±15–50). Hard limit ±50°.
- head pan/tilt: typical ±8–30° per beat.
- right_arm/left_arm on x/y/z: |value| > 1 → degrees; |value| ≤ 1 → meters.

[Path steps — EE IK or base Cartesian draw]
Use `type: "path"` to draw a **straight line or arc in world space**.
**Never include arm `joint` on path.** Set `path.mode` explicitly.

6. EE line path (`path.mode: "ee"`, `shape: "line"`):
- Translate EE parallel to one world axis.
- Fields: `axis` ∈ {x, y, z}, `distance` (meters, signed), `speed`, optional `hold_time`, optional `repetition`, optional `side` (right|left|both).
- Typical `distance`: 0.03–0.25 m (local stroke 0.03–0.08 m; reach/slash up to ~0.25 m).

7. EE arc path (`path.mode: "ee"`, `shape: "arc"`):
- Draw an arc in plane `xy`, `yz`, or `xz`.
- Fields: `plane`, `radius` (meters), `sweep` or `degrees`, optional `direction` cw|ccw, `speed`, optional `hold_time`, optional `repetition`.
- Typical: `radius` 0.03–0.20 m, `sweep` 45–720° for scratches, circles, wiping.
- Optional `side`: right | left | both for bilateral paths.

8. Base path (`path.mode: "base"`):
- Line: `shape: "line"`, set `x` and/or `y` (meters, signed forward/left).
- Arc: `shape: "arc"`, `radius` (m), `degrees` (turn amount).
